# CLAUDE.md

> `CLAUDE.md` and `AGENTS.md` are autogenerated by `/Init`. Do not edit directly -- run `/Update` to regenerate.

Developer discipline skills and agents for the forge ecosystem — code quality, testing, defensive programming, debugging, git workflows, and code review.

## Install / Verify

```bash
make install          # deploy skills + agents (Claude, Gemini, Codex, OpenCode) and activate git hooks
make validate         # run the pre-commit validation chain
make clean            # remove build artifacts
```

Requires the `forge` CLI on PATH ([forge-cli](https://github.com/N4M3Z/forge-cli)). Install via `cargo install --locked forge-cli` or run `INSTALL.md`.

## Architecture

```text
skills/               skill directories — SKILL.md + optional @-included companions
  FixCI/scripts/      optional executable helpers with their own provenance sidecars
agents/               agent markdown files (flat directory)
docs/decisions/       ADRs (structured-madr frontmatter)
rules/                always-loaded behavioral rules
defaults.yaml         module defaults
config.yaml           user overrides (gitignored)
module.yaml           module metadata
.claude-plugin/       Claude Code plugin discovery
.provenance/          SLSA sidecars for every versioned file
```

Platform directories (`.claude/`, `.gemini/`, `.codex/`, `.opencode/`) are generated by `make install` and gitignored. Source of truth is `skills/`, `agents/`, `rules/`, and the adjacent metadata.

## Conventions

- Skills are guidance documents, not tool wrappers. They teach patterns and workflows.
- CodeCleanup is the tactical workflow; DefensiveProgramming provides the principles it references.
- RustDevelopment is Rust-specific; CodeCleanup and DefensiveProgramming are language-agnostic.
- Adopted upstream content ships with a SLSA provenance sidecar under `.provenance/`; see `SECURITY.md` for the audit path and pin-bump policy.

## Git

Conventional Commits: `type: description`. Lowercase, no trailing period, no scope.

Types: `feat`, `fix`, `docs`, `chore`, `refactor`, `test`.

Pre-commit hook (`.githooks/pre-commit`) runs validation via `prek` or `forge validate` with a hash-pinned `validate.sh` fallback.
