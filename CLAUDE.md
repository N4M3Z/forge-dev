# CLAUDE.md

> `CLAUDE.md` and `AGENTS.md` are autogenerated by `/Init`. Do not edit directly -- run `/Update` to regenerate.

Developer discipline skills for the forge ecosystem — code quality, testing, defensive programming, git conventions.

## Install / Verify

```bash
make install          # deploy skills (Claude, Gemini, Codex, OpenCode)
make verify           # check skills deployed across all providers
make clean            # remove previously installed skills
make test             # validate-module convention checks
make lint             # mdschema + shellcheck
```

## Skills

| Skill | What it does |
|-------|-------------|
| **CodeCleanup** | Proactive code cleanup — duplication removal, pattern adoption, readability maximization |
| **DefensiveProgramming** | Defensive coding principles — input validation, error boundaries, fail-safe defaults |
| **RustDevelopment** | Rust conventions — crate structure, error handling, CLI patterns, config loading |
| **TestDrivenDevelopment** | Test discipline — Red-Green-Refactor, test categories, coverage strategy |
| **Git** | Git best practices — conventional commits, submodule workflows |

## Architecture

```
skills/
  CodeCleanup/             SKILL.md + sample.md (cleanup workflow with before/after demo)
  DefensiveProgramming/    SKILL.md (coding principles — input validation, error boundaries)
  RustDevelopment/         SKILL.md + SKILL.yaml (Rust ecosystem conventions)
  TestDrivenDevelopment/   SKILL.md + SKILL.yaml (testing discipline)
  Git/                     SKILL.md + SKILL.yaml (git conventions for forge multi-repo)
lib/                       git submodule -> forge-lib (Rust binaries)
defaults.yaml              skill roster
config.yaml                user overrides (gitignored), same structure as defaults
module.yaml                module metadata (name, version)
.claude-plugin/            plugin.json manifest for Claude Code plugin discovery
```

Platform directories (`.claude/`, `.gemini/`, `.codex/`, `.opencode/`) are generated by `make install` and gitignored. Source of truth is `skills/` and `defaults.yaml`.

## Conventions

- These skills are guidance documents, not tool wrappers. They teach patterns and workflows.
- CodeCleanup is the tactical workflow; DefensiveProgramming provides the principles it references.
- RustDevelopment is Rust-specific; CodeCleanup is language-agnostic.
